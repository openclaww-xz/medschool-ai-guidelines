# UC — AI Guidelines (ai.uc.edu)

## Authority / Authorship
- University of Cincinnati AI initiative ("AI is a powerful partner... a compass for ethical and practical application").

## Clause inventory
1. Sign into UC-licensed tools ("privacy-protected access to approved AI").
2. Public-data-only rule: "Neither controlled nor restricted data are approved for use in AI tools"; examples of public data; "UC student directory data is not approved."
3. Personal-information caution even with public data (aggregation risk).
4. Legal/ethical compliance (copyright).
5. Students: check with faculty; read syllabi; Student Code alignment.
6. Research: "Investigators are encouraged to indicate in the project description the extent to which, if any, generative AI technology was used" in proposals; NSF/NIH peer-review notices; UNESCO ethics link.

## Classification
- **cautious-informed** — compass-style guidance with the rare proposal-disclosure encouragement; Bearcats GPT provisioned (see students page).
