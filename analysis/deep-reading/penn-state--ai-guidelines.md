# Penn State — AI Guidelines (ai.psu.edu)

## Authority / Authorship
- Penn State university AI initiative.

## Complete clause inventory
1. Statutes: FERPA, HIPAA, GLBA.
2. Disclosure routing: students→instructors; staff→supervisors; researchers→journal editors.
3. Verify output (bias, discrimination, "appropriate citations to real sources").
4. **Accessibility regime**: "When an AI tool is used by more than one person... an accessibility review is required" (Policy AD69); EEAAP process with pre-reviewed templates for ChatGPT free, Copilot free, M365 Copilot.
5. **AI-assisted grading = courseware**: department-head + dean approval (email) required; courseware@psu.edu registration; Reviewed Courseware List.
6. Copyright: AI output ownership varies; training-data risk.
7. Images: "Use Adobe Firefly... trained exclusively on licensed and public domain content" for distributed materials; other generators need comms/legal consult.

## Sophistication markers
- The only guidance page with an operational AI-grading approval workflow and accessibility EEAAP templates; approved-image-tool policy.
