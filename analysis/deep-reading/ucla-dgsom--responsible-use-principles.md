# UCLA DTS — Guiding Principles for Responsible Use of AI (DGSOM-relevant)

## Authority / Authorship
- UCLA Digital Technology Services; routes to Academic Senate GenAI guidance and Teaching & Learning Center.

## Complete clause inventory
1. Student Conduct Code applied to GenAI: "Unless otherwise specified by the faculty member, all submissions…must either be the Student's own work, or must clearly acknowledge the source."
2. Privacy: explicit informed consent before data use; anonymized datasets "wherever possible."
3. Security: MFA, encryption at rest/in transit, access controls; Available GenAI Tools matrix for data classifications; "Refrain from entering any sensitive data... unless the tool has been specifically cleared for P3-P4 classified data."
4. Ethics: bias/fairness evaluation; decision transparency; sustainability awareness.
5. Limitations: hallucinations; bias; IP-infringement risk ("Always use commercially licensed GenAI tools to minimize the risks"); source transparency.
6. Human-in-the-loop & accountability; developer responsibility for model-based decisions.

## Classification
- **cautious-informed** — the Conduct-Code quotation makes the acknowledgment default explicit; otherwise standard UC-pattern guidance (cf. UCSD).
