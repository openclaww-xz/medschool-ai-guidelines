# UMN IT — Appropriate Use of Generative AI Tools

## Authority / Authorship
- University of Minnesota IT (system-wide; Medical School context via addendum reference).

## Clause inventory
1. "Know your data": Public data freely usable; per-tool matrix (ChatGPT Edu: Public+Private-Restricted, no Health; Gemini: incl. Acceptable-Use tiers; Copilot; ZoomMate) against Data Security Classification.
2. UMN-Licensed tools encouraged (Master License Agreements).
3. Ethics via Office for Institutional Compliance five values.
4. Software review process incl. unpaid versions; vendor review.
5. Students: "instructor expectations... is paramount. Just because an AI tool exists doesn't mean you can use it for every assignment."
6. Staff consult managers; faculty/researchers follow granting-agency AI policies.
7. Human verification of outputs; "AI-generated code should not be used for institutional IT systems... unless it is reviewed by a technologist."
8. **Licensing restrictions**: "Publishers typically prohibit (through licensing) upload of research, magazine, and newspaper articles (including those used for course readings) to third-party services like AI tools."
9. Clickwrap contracts must go to OGC before acceptance.

## Classification
- **cautious-informed (IT layer)** — solid classification matrix + two underrated clauses (licensed-content upload ban; AI-code review requirement); pedagogy deferred (Medical School SIR addendum referenced, separate note).
