# WVSOM — Potential Misuse and Data Sharing

## Authority / Authorship
- WVSOM institutional web guidance (IT-adjacent, linked to HIPAA policy and data-access procedures).

## Philosophy (verbatim framing)
- "When you provide information to these tools, such as queries, student essays, grant proposals, source code or datasets, it is the same as posting information on a public website."
- "WVSOM encourages the use of generative AI services, as long as no institutional data is submitted to them without approval."

## Clause inventory
1. Permissive-by-default posture for AI use, gated on data submission.
2. "Currently, Microsoft 365 Copilot is the only generative AI permitted" for institutional data.
3. Review requirement for any other system: contracts + safeguards + "algorithms in use are ethical, transparent and beneficial."
4. Never submit (even anonymized): Institutional-Data-or-higher; HIPAA data; others' IP "unless the individual submitting that intellectual property created it."
5. Five concrete prohibited examples incl. "Asking an unsupported/approved AI model to summarize and grade a student paper" and sharing grant proposals under review.

## Sophistication markers
- Grading-use prohibition (faculty entering student work) — rare in guidance layer; anonymized-data caution; named sole approved tool.

## Classification
- **progressive-structured** — encourage-plus-gate posture, unusually concrete prohibited-example list for a small school.
