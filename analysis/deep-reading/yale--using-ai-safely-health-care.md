# Yale — Using AI Safely and Responsibly in Health Care and Research

## Authority / Authorship
- ai.yale.edu (YSM, YSPH, YSN, Yale Health scope).

## Complete clause inventory
1. **Minimum Necessary principle**: "Enter only the information needed for the AI task"; "Whenever possible, use de-identified or synthetic data instead of actual patient data"; "Never submit direct identifiers... unless absolutely necessary"; "When unsure, leave it out."
2. Use tools as intended — "Using a tool outside its intended use can create legal, ethical, or clinical risks."
3. Security first: Security Planning Assessment before any new tool; Security Design Review for health-system settings.
4. Fit-for-purpose matching; tools marketed as "HIPAA-compliance" may "not meet these standards."
5. "AI tools are not authorized to provide diagnoses, treatment recommendations, or risk stratification unless formally approved through clinical governance channels."
6. Allowed list includes "deployed AI tools for clinical practice and decision support such as Abridge and EPIC applications for activities such as ambient note drafting, denial letter suppo[rt]..."

## Sophistication markers
- Minimum-Necessary is a HIPAA-minimum-necessary import — the only explicit synthetic-data-preference clause in the guidance corpus; names deployed ambient tools (Abridge, Epic).

## Classification
- **progressive-structured** — clinically literate governance; stronger than the run-27 'Standards' stub suggested.
