## Quick Start: How to Access 

- Visit m365.cloud.microsoft/chat and sign in with your CWID and password to use the protected version. Copilot works on any browser; for the most features, use the Microsoft Edge browser. (IT@Cornell, " Start Using Copilot")
- In Teams: Click the Copilot icon in your Teams sidebar.

## What is Microsoft Copilot? 

Microsoft Copilot is an AI-powered assistant that helps you with various tasks and queries.

- No web search on Copilot Enterprise as licensed by WCM and NYP: The WCM/NYP-licensed version of Copilot Enterprise will not pull the latest research. Use PubMed, Embase, and library databases for authoritative information.
