Understanding AI

What is Generative AI?

Generative AI refers to deep-learning models that are trained on large amounts of data in order to learn patterns, which are then stored in a model. Generative AI has the ability to actually create or generate new content, including text, images, audio, video, code, and other content. Users interact, not with the model directly, but with an interface layer using prompts. Some common examples of these tools include conversational agents like ChatGPT and Google Gemini; and coding assistants like GitHub Copilot.
