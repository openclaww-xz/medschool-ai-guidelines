AI, Machine Learning, and Research

There are many tools that utilize AI and machine learning to assist with the research process. Remember that these tools can make mistakes and should not be taken as always 100% accurate. It is essential for you to verify their work appropriate to the context in which you will be using them.

Note that many of these tools are very similar.

Research Tools

Consensus
This link opens in a new window

Consensus is a search engine that allows you to find answers from scientific research. You can enter a question and it will provide a list of literature, all with summaries of their findings as they relate to your questions. You need to create a free account to use Consensus.

Elicit.org
This link opens in a new window

Elicit.org allows you to enter a research question and it will return relevant scholarly literature. It will provide a short summary of the literature to answer your question. It will also list the literature and a one-sentence abstract summary of each. You can also run this analysis on your own PDFs.

Perplexity
This link opens in a new window

Perplexity is a conversational search engine. You can select if you want the results to be more academic, all of the internet, and more. You can also upload files of your own and ask questions about them.

Research Rabbit
This link opens in a new window

Research Rabbit helps you to visualize connections between research through interactive literature maps. This can help you find relevant research and explore citations. You need to create a free account to use it.

Semantic Scholar
This link opens in a new window

Semantic Scholar uses AI to provide short summaries of scientific literature.

System Pro
This link opens in a new window

Summarizes papers and gives an overview summary of them to answer your question/topical search. Only searches PubMed.
